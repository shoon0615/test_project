# 진행 기록과 학습 노트

## 2026-11-26 · 첫 FO 게시판

**요약** · 빈 폴더에 글 목록·상세·작성·수정·삭제를 추가했다. Docker 밖의 브라우저에서 접속할 수 있도록 서버의 수신 주소를 실행할 때 선택하게 했다.

**자세히** · 글을 저장하면 브라우저가 제목과 본문을 JSON으로 보낸다. 서버는 입력을 확인하고 ID와 작성일을 붙여 메모리에 저장한다. 화면과 API를 한 서버에서 제공해 명령 하나로 실행할 수 있다. Docker에서는 포트를 연결해도 서버가 컨테이너 내부의 `127.0.0.1`만 듣고 있으면 밖에서 접속할 수 없어 `HOST=0.0.0.0`으로 실행한다.

| API | 하는 일 |
| --- | --- |
| `GET /api/posts` | 목록 조회 |
| `GET /api/posts/{id}` | 상세 조회 |
| `POST /api/posts` | 글 작성 |
| `PUT /api/posts/{id}` | 제목과 본문 수정 |
| `DELETE /api/posts/{id}` | 글 삭제 |

**확인** · 이 폴더에서 `node --test`를 실행하면 API의 글 작성부터 삭제까지 확인한다.

## 지금 볼 용어

- **화면** · HTML은 구조, CSS는 모양, JavaScript는 버튼 동작을 맡는다.
- **통신** · API는 브라우저가 서버에 글을 가져오거나 저장해 달라고 요청하는 약속이다. 개발자 도구의 **Network** 탭을 띄우고 글을 저장하면 `POST /api/posts` 요청을 볼 수 있다.
- **FO와 BO** · FO는 글을 읽고 쓰는 사용자 영역이고, BO는 신고된 글을 숨기는 등 운영 작업을 하는 관리자 영역이다.
